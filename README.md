# Dar Aldwa — Independent Cloudflare edition

Full Arabic / English company website and CMS, exported for your own Cloudflare Workers, D1 and R2 account. Start with **ابدأ-هنا.md** and **README-AR.md**.

No ChatGPT sign-in, no default password, no embedded account credentials. This package contains the authored website content and local assets; live CMS edits and uploads must be exported from the existing admin and imported separately.

Requires Node.js >=22.13, pnpm 11.25 and a Cloudflare account with Workers, D1 and R2 enabled. This is a dynamic Worker application, not a Cloudflare Pages drag-and-drop static ZIP.
