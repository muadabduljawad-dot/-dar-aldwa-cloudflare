# موقع شركة دار الدواء

موقع مؤسسي متعدد الصفحات بالعربية والإنجليزية، مع إدارة محتوى وD1 وR2.

## التشغيل المستقل على Cloudflare

اقرأ «ابدأ-هنا.md» لمسار GitHub الملائم للاستخدام من الهاتف. هذه النسخة مستقلة عن Sites وتستخدم جلسات البريد وكلمة المرور فقط؛ لا تعتمد على رؤوس هوية من خارج التطبيق. لا توجد بيانات دخول افتراضية.

على جهاز به Terminal: ثبّت Node.js 22.13 أو أحدث وpnpm 11.25.0. ثم نفّذ من مجلد المشروع:

```sh
pnpm install --frozen-lockfile
pnpm exec wrangler login
pnpm exec wrangler d1 create dar-aldwa-content
pnpm exec wrangler r2 bucket create dar-aldwa-media
```

حدّث database_id في wrangler.jsonc بالمعرّف الحقيقي، وحدّث PUBLIC_SITE_URL برابطك HTTPS. أبق الربط DB وBUCKET كما هو، ثم:

```sh
pnpm db:remote
pnpm admin:create
pnpm check
pnpm test
pnpm build
pnpm run deploy
```

أداة admin:create تطلب البريد وكلمة المرور مخفية، وتطلب تحديد remote أو local؛ الافتراضي remote. لا تحفظ كلمة المرور في سطر الأوامر. تستخدم الأداة PBKDF2 وتلغي جلسات الحساب القديمة عند إعادة تعيينه. تحتاج صلاحية Cloudflare لإدارة D1؛ إعدادها لا يعتمد على نموذج ويب مفتوح.

محليًا نفّذ `pnpm db:local` ثم `pnpm admin:create` واختر local، ثم `pnpm dev`. الجلسات Secure وتحتاج HTTPS أو سياق localhost الموثوق في المتصفح؛ لا تُزل خاصية Secure لتجربة الإدارة.

للاستخدام البرمجي يمكن تمرير JSON على stdin إلى `pnpm admin:stdin` يحتوي email وpassword وremote؛ لا تضع ملف الإدخال في Git. للاستعادة استخدم admin:create من جهاز موثوق. حساب مدير آخر يستطيع إدارة الحسابات من اللوحة. لا توجد استعادة برسالة بريدية قبل ربط خدمة إرسال.

ملفات البناء تنتج داخل dist، ويحوّل ملحق Cloudflare إعدادات الموارد من wrangler.jsonc إلى ملف النشر. لا تعدّل dist/server/wrangler.json يدويًا؛ عدّل إعداد الجذر ثم أعد البناء. لا تشغّل pnpm run deploy قبل البناء. يمكنك فحص الحزمة دون نشر باستخدام `pnpm exec wrangler deploy --dry-run`.

الصلاحيات: مدير كامل، محرر مسودات ووسائط وطلبات دون نشر، وعرض فقط. الموقع عام على حسابك بعد نشر Worker؛ لوحة الإدارة محمية بالجلسات على الخادم. لا تحتوي الحزمة على سجلات الاستفسارات أو بيانات دخول البيئة السابقة.

## التعديل والنشر

الصفحات والأقسام: النصوص باللغتين، الصور، نوع القسم، البطاقات، الروابط، الإخفاء والحذف والترتيب بالسحب أو الأزرار. احفظ المسودة ثم عاين الهاتف/التابلت/الكمبيوتر ثم انشر. الإصدارات تحفظ المحتوى السابق للنشر. استعادة إصدار تنقله إلى المسودة دون نشر تلقائي.

سلة المحذوفات تحفظ العناصر بعد حفظ المسودة. لا يوجد محرر HTML حر؛ المحتوى في حقول منظمة لتجنب إدخال أكواد ضارة.

الهوية: الاسم والشعار العربي والإنجليزي والنبذة والعنوان والأرقام والبريد وفيسبوك وواتساب. البريد وفيسبوك فارغان عمدًا، ويظهران في الموقع بعد إضافتهما. الشعار المرفق ثنائي اللغة ومحفوظ بهويته الأصلية.

المظهر: ألوان وخط وحجم شعار وحجم نص ومسافات ولغة ومظهر افتراضي وتمويجات وتعتيم وموضع صورة البانر. قسم العبارات المشتركة يحرر نصوص الأزرار والقوائم والنماذج باللغتين.

## الصور والطلبات

الصور الأصلية محفوظة محليًا داخل public/images. مصادرها في image-sources.json. صور توضيحية ولا تمثل مخزون الشركة أو ممتلكاتها. لم تُدرج شهادات أو مشاريع أو عملاء وهميون. الخطوط من Google Fonts وتحتاج اتصالًا بالإنترنت؛ توجد خطوط بديلة عند تعذر تحميلها.

مكتبات مستقلة للصور والفيديوهات وملفات PDF. الرفع يقبل JPG / PNG / WEBP حتى 8MB، وPDF حتى 12MB، وفيديو MP4 / WEBM حتى 40MB لكل ملف. تُضغط الصور الكبيرة قبل الرفع، وتُفحص صيغة كل ملف على الخادم قبل حفظه في R2. ملفات مكتبة الموقع عامة؛ مرفقات نموذج الاستفسار خاصة ولا تُفتح إلا لمستخدم مخول. يدعم خادم الفيديو طلبات HTTP Range للتقديم داخل المقطع. يمكن عرض فيديو أكبر عبر رابط YouTube أو Vimeo بدل رفعه.

نموذج التواصل يحفظ الطلب فعليًا داخل D1 ويمنح رقم متابعة. تظهر الطلبات في لوحة الإدارة ويمكن تعديل حالتها. إرسال إشعارات بريدية غير مفعّل لأن البريد وخدمة الإرسال غير مقدّمين. لا يرسل النموذج إلى عنوان وهمي.

## النسخ الاحتياطي

من اللوحة يمكن تصدير المحتوى والإصدارات ووسائط R2 المرفوعة حتى 24MB في ملف JSON. الاستيراد يعيد المحتوى إلى المسودة مع حفظ نسختها السابقة. الوسائط الأصلية تأتي مع الكود في ZIP. النسخ الشامل للطلبات والمستخدمين وقاعدة D1 يتم من حساب الاستضافة، ولا يصدّر ملف المحتوى كلمات المرور أو الجلسات. للمشاريع ذات وسائط أكبر استخدم تصدير D1 وR2 من Cloudflare.

## الاختبارات

`node tests/integration.mjs` لاختبار الصلاحيات والجلسات والمسودات والنشر والاستعادة والوسائط والطلبات والنسخ الاحتياطي على D1 وR2 محليتين معزولتين. `pnpm exec tsc --noEmit` لفحص الأنواع. راجع docs/test-results.txt للنتيجة. تشمل الاختبارات أيضًا رفع فيديو MP4 فعلي، نطاقات الفيديو، ملفات PDF، حفظ ونشر الأقسام العشرة المضافة، ورفض روابط التضمين غير المسموحة.

## إعدادات باقية

- اختيار البريد الرسمي وإضافته.
- إدخال الرابط الحقيقي لصفحة فيسبوك.
- ربط بريد موثّق وخدمة إرسال إذا أردت الإشعارات والاستعادة البريدية.
- ربط الدومين الخاص وتحديد الجمهور المناسب للنشر العام. المعاينة المنشورة تبدأ خاصة بالمالك.
- تكاليف الاستضافة والتخزين والبريد مرتبطة بخطة المزوّد واستهلاكها؛ لا تتضمن هذه الملفات اشتراكًا مدفوعًا أو دومينًا.

## منشئ المحتوى الموسّع

من «إضافة محتوى جديد» اختر الصفحة ثم أحد 20 نوعًا: بانر، مقدمة، نص وصورة، خدمات، شبكة بطاقات، خطوات، معرض، دعوة للتواصل، نموذج تواصل، نص، فيديو، سلايدر، أسئلة شائعة، كتالوج منتجات، تنزيل ملفات، شعارات، فريق، أخبار، خريطة، وفاصل. يفتح النوع مباشرة في محرر الصفحة. الأنواع التي تحتاج عناصر تبدأ فارغة لتضيف محتوى الشركة الصحيح.

يمكن إنشاء صفحة مستقلة باسم عربي وإنجليزي ورابط فريد، وإضافة الأقسام ونسخها وإعادة ترتيبها بالسحب أو الأسهم وإخفائها. إعدادات القسم تشمل الخلفية والمحاذاة والأعمدة والعرض والمسافة الرأسية وإخفاءه على الهاتف أو الكمبيوتر. التراجع والإعادة يحتفظان بآخر 40 تعديلًا في جلسة التحرير؛ الإصدارات المحفوظة في قاعدة البيانات متاحة للاستعادة بعد الخروج.

قسم الفيديو يقبل ملفًا من المكتبة أو رابط YouTube / Vimeo، مع غلاف وتعليق باللغتين. قسم التنزيلات يربط ملفات PDF بعناوين وأوصاف. الخريطة تقبل رابط تضمين Google Maps فقط. لا يقبل النظام HTML أو iframe عشوائيًا.

الرفع لا ينشر الملف تلقائيًا داخل صفحة: اختر «استخدم في قسم جديد»، أو اختره من محرر القسم، ثم احفظ المسودة وراجع المعاينة وانشر. حد النسخة الاحتياطية المباشرة 24MB لمجموع الوسائط؛ عند تجاوزه استخدم نسخ D1 وR2 من حساب Cloudflare. محتوى الشركة والشعار محفوظان في المصدر الافتراضي.
